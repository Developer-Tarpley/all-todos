# ⭐ 3. **useNotes() Hook (Core Business Logic)**

This hook is the heart of Sprint 1.

### Responsibilities:
- CRUD operations  
- Auto‑save integration  
- Persistence (via adapter)  
- Timestamp updates  
- Selecting active note  

### Internal structure:

```js
function useNotes() {
  const [notes, setNotes] = useState([]);
  const [activeNoteId, setActiveNoteId] = useState(null);

  const createNote = () => { ... }
  const updateNote = (id, updates) => { ... }
  const selectNote = (id) => { ... }

  useEffect(() => persist(notes), [notes]);

  return { notes, activeNoteId, createNote, updateNote, selectNote };
}
```

This keeps all note logic in one place.

# ⭐ 4. **Persistence Layer (localStorageAdapter)**

### Responsibilities:
- Save notes to localStorage  
- Load notes on startup  
- Handle JSON parsing errors  
- Provide migration hooks for future versions  

### API:

```js
loadNotes(): Note[]
saveNotes(notes: Note[]): void
```

### Why an adapter?
Because later you can swap:

- localStorage → IndexedDB  
- IndexedDB → Cloud sync  
- Cloud sync → Multi‑device sync  

Without touching the UI.

---

# ⭐ 5. **Auto‑Save Architecture**

### useAutoSave(note, updateNote)
- Watches title/body changes  
- Debounces updates (300ms)  
- Calls `updateNote(id, { title, body })`  
- Updates `updatedAt` timestamp  
- Triggers AutoSaveIndicator state  

### AutoSaveIndicator states:
- `"idle"`
- `"saving"`
- `"saved"`
- `"error"`

This gives you a smooth, modern UX.

---

# ⭐ 6. **Component Communication Flow**

### Sidebar → Editor
User clicks a note:

```
NoteListItem → selectNote(id)
```

Editor receives:

```
activeNote = notes.find(n => n.id === activeNoteId)
```

### Editor → useNotes
User types:

```
NoteTitleInput → updateNote(id, { title })
NoteBodyEditor → updateNote(id, { body })
```

### useNotes → Persistence
Whenever notes change:

```
useEffect(() => saveNotes(notes), [notes])
```

### Persistence → App
On load:

```
const initialNotes = loadNotes()
```

# ⭐ 7. **Error Handling Architecture**

### GlobalErrorBoundary
Catches:
- Rendering errors  
- Editor crashes  
- Unexpected exceptions  

### Persistence Errors
If `loadNotes()` fails:
- Show fallback UI  
- Reset notes to empty array  

If `saveNotes()` fails:
- AutoSaveIndicator shows `"error"`  
- Editor continues working (non‑blocking)

# ⭐ 8. **Performance Considerations**

### Memoization
- Memoize `NoteListItem`  
- Memoize `NoteEditor` subcomponents  
- Prevent full re-renders on every keystroke  

### Debounce
- Auto‑save uses 300ms debounce  
- Prevents excessive writes  

### Lazy Loading
- Load notes before rendering editor  
- Show skeleton UI if needed

# ⭐ 2. `src/state/NotesProvider.jsx`

```jsx
import { useState, useEffect, useCallback } from "react";
import { NotesContext } from "./NotesContext";
import { loadNotes, saveNotes } from "../utils/storage/localStorageAdapter";
import { generateId } from "../utils/generateId";
import { now } from "../utils/timestamps";

export default function NotesProvider({ children }) {
  const [notes, setNotes] = useState(() => loadNotes());
  const [activeNoteId, setActiveNoteId] = useState(null);

  const createNote = useCallback(() => {
    const id = generateId();
    const newNote = {
      id,
      title: "",
      body: "",
      createdAt: now(),
      updatedAt: now()
    };

    setNotes(prev => [newNote, ...prev]);
    setActiveNoteId(id);
  }, []);

  const updateNote = useCallback((id, updates) => {
    setNotes(prev =>
      prev.map(note =>
        note.id === id
          ? { ...note, ...updates, updatedAt: now() }
          : note
      )
    );
  }, []);

  const selectNote = useCallback(id => {
    setActiveNoteId(id);
  }, []);

  useEffect(() => {
    saveNotes(notes);
  }, [notes]);

  return (
    <NotesContext.Provider
      value={{
        notes,
        activeNoteId,
        createNote,
        updateNote,
        selectNote
      }}
    >
      {children}
    </NotesContext.Provider>
  );
}
```

# ⭐ 4. `src/utils/storage/localStorageAdapter.js`

```jsx
const KEY = "notehub_v2_notes";

export function loadNotes() {
  try {
    const raw = localStorage.getItem(KEY);
    if (!raw) return [];
    return JSON.parse(raw);
  } catch {
    return [];
  }
}

export function saveNotes(notes) {
  try {
    localStorage.setItem(KEY, JSON.stringify(notes));
  } catch {
    // non-blocking error
  }
}
```

This is intentionally simple — you’ll expand it later.
